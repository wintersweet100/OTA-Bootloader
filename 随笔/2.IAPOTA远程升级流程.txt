#### Flash分区规划（以STM32F103ZET6为例，512KB Flash）

```
0x08000000 - 0x08007FFF   Bootloader区    (32KB)
0x08008000 - 0x08008FFF   参数区          (4KB)
0x08009000 - 0x08028FFF   运行区          (128KB = 0x20000)
0x08029000 - 0x0804FFFF   A存储区         (128KB)
0x08050000 - 0x0807FFFF   B存储区         (128KB)
										共计420KB
```

```
Boot启动 -> 等待升级指令 -> 超时则加载App -> App运行 -> 支持多种接口升级
```

#### 设置SCB-VTOR寄存器重定位中断向量表*

为什么要重定位？

- **Bootloader** 有自己的向量表（比如在 0x08000000）
- **应用程序** 也有自己的向量表（比如在 0x08040000）
- 当从 Bootloader 跳转到应用程序时，需要告诉 CPU：
  - "现在使用应用程序的向量表，而不是 Bootloader 的向量表"

#### 小结：(实现APP自我复制到RAM中运行代码)

情况一、不使用指针跳转的时候，即使RAM中没有对应的数据也仍然可以正常运行。

情况二、使用函数指针进行跳转，那么因为运行地址在RAM中且RAM中没有加载代码，所以无法正常运行。

情况三、使用函数指针进行跳转 且flash中APP程序自我复制进RAM中，代码可以正常运行。
